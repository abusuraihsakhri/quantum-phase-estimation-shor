Quantum Phase Estimation & Shor Order Finding

Interactive, dependency-free simulations of phase estimation and modular order finding. Runs entirely in the browser; no server, API key, or data upload.

Phase estimation

Estimate the eigenphase of a unitary with eigenvalue exp(2πiφ). Phases are periodic modulo 1.

Plot shows the 12 most probable measurement outcomes, indexed from zero. The full distribution is used in calculations.

Modular order finding

Simulate controlled modular multiplication on a work register, inverse QFT, and continued-fraction order reconstruction.

Requires 2 ≤ a < N ≤ 63 and gcd(a,N)=1. Some runs with insufficient precision do not recover an order.

About the simulation

Phase estimation uses the exact finite-register measurement distribution. The modular example constructs amplitudes for the entangled state |j⟩|aj mod N⟩, traces out the work register, and evaluates the inverse Fourier transform. It then checks candidate orders using modular exponentiation. The classical order shown separately is a verification reference, not an input to the simulated quantum distribution.

This is an educational state-vector simulator, not quantum hardware or a scalable factoring implementation. No personal data should be entered. Computations remain in this browser tab; nothing is saved or transmitted by the application.
